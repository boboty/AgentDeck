Headline KPI figure — mono numerals signal data credibility. For result bands, case cards and slides.

```jsx
<Metric value="+38%" label="审核效率提升" delta="12pp" trend="up" />
<Metric value="4.2×" label="ROI" caption="12 个月回收期" size="lg" align="center" />
```

`delta` + `trend` render a colored up/down/flat chip. `size` scales the figure; `align="center"` for centered stat bands.
