Signature all-caps kicker that introduces a heading on slides, hero units and section openers.

```jsx
<Eyebrow>Methodology · 方法论</Eyebrow>
<Eyebrow tone="onDark">Module 03</Eyebrow>
<Eyebrow tick={false} tone="muted">Case study</Eyebrow>
```

Use `tone="onDark"` over ink/dark backgrounds. Keep it short — one short phrase, optionally bilingual with a `·` separator.
