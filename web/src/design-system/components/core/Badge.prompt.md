Small status / category label for cards, slides and tables.

```jsx
<Badge tone="brand">实战案例</Badge>
<Badge tone="success" dot>已落地</Badge>
<Badge tone="warning" solid>试点中</Badge>
```

Tones: `brand | neutral | success | warning | risk | info`. `solid` for filled, `dot` for a leading status dot. Keep labels to 1–3 words.
