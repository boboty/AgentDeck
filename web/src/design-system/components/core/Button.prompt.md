Primary action control — use for any clickable call-to-action across slides, web pages and workshop UIs.

```jsx
<Button variant="primary" size="md" iconRight="→">报名课程</Button>
<Button variant="secondary">查看大纲</Button>
<Button variant="ghost" size="sm">Learn more</Button>
```

Variants: `primary` (emerald fill, the default CTA), `secondary` (ink outline on white), `ghost` (text-only brand), `dark` (ink fill, for use on light hero bands), `soft` (mint tint). Sizes `sm | md | lg`. Pass `full` to stretch, `iconLeft`/`iconRight` for icon nodes, `disabled` to dim. Hover darkens via brightness; press nudges down 1px.
