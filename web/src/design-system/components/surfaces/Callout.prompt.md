Note / tip / warning block with a left brand keyline. For methodology asides and key takeaways.

```jsx
<Callout title="方法论提示">
  先识别高价值、低风险的场景，再进入规模化落地。
</Callout>
<Callout tone="warning" icon="!">数据合规需在试点前确认。</Callout>
```

Tones: `brand | neutral | warning | risk | info`. Pass `title` for a bold lead line and `icon` for a leading glyph.
