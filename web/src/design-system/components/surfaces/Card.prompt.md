Base surface for grouping content — the building block for grids, panels and feature lists.

```jsx
<Card accent elevation="md">
  <h3>研发体系建设</h3>
  <p>从试点到规模化的结构化路径。</p>
</Card>
```

`accent` adds the brand top-left rule; `interactive` lifts on hover (use for clickable cards); `elevation` controls shadow; `pad` sets inner padding.
